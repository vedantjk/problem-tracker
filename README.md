# problem-tracker

Accountability memory for my LeetCode / CSES interview prep.

Scheduled Claude routines check in (weekdays 9 AM PT, weekends 1 PM PT), nudge me, and
maintain [`log.md`](./log.md) (daily journal) and [`tracker.md`](./tracker.md) (full problem list).
Both files are maintained by the routine — avoid hand-editing except to fix a mistake.
